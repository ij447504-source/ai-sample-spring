# Spring Boot Demo Project

## 목적

이 문서는 AI 에이전트가 Spring Boot 기반의 웹 애플리케이션 프로젝트 구조를 이해하고, 효과적으로 코드를 탐색하고 수정할 수 있도록 돕는 최상위 가이드입니다.

## 주요 파일

| 파일명 | 설명 |
| --- | --- |
| `build.gradle` | 프로젝트의 의존성 및 빌드 설정을 관리하는 Gradle 파일입니다. |
| `AI-GUIDE.md` | AI 에이전트가 따라야 할 최우선 규칙과 작업 절차를 정의합니다. |
| `settings.gradle` | Gradle 멀티-프로젝트 빌드 구성을 정의합니다. |
| `gradlew` / `gradlew.bat` | Gradle Wrapper 실행 스크립트입니다. OS에 맞춰 사용하세요. |

## 하위 디렉토리

- `src/` - 모든 애플리케이션 소스 코드와 리소스 파일이 위치합니다.
- `.ai/` - AI 에이전트의 작동을 제어하는 규칙, 스킬, 훅(hook)을 정의합니다.
- `.person/` - 개인화된 설정이나 로그 등, 사용자별 파일들을 관리합니다.
- `build/` - Gradle에 의해 생성된 빌드 산출물이 저장되는 디렉토리입니다. (AI는 수정하지 않음)
- `gradle/` - Gradle Wrapper 관련 파일이 위치합니다. (AI는 수정하지 않음)

## AI 작업 지침

1.  **가이드 숙지**: 작업을 시작하기 전, 항상 `AI-GUIDE.md` 파일과 각 디렉토리의 `AI-CONTEXT.md` 파일을 먼저 읽고 규칙을 숙지하세요.
2.  **계층적 탐색**: 코드베이스를 이해할 때는 이 파일부터 시작하여, 하위 디렉토리의 `AI-CONTEXT.md`로 순차적으로 이동하며 세부 정보를 파악하세요.
3.  **의존성 관리**: 새로운 라이브러리가 필요한 경우, `build.gradle` 파일의 `dependencies` 블록에 추가합니다.
4.  **빌드 및 테스트**: 코드 수정 후에는 반드시 `./gradlew build` 및 `./gradlew test` 명령을 실행하여 프로젝트가 정상적으로 빌드되고 모든 테스트를 통과하는지 확인해야 합니다.

## 테스트

- 프로젝트 전체 테스트 실행: `./gradlew test`
- 프로젝트 빌드: `./gradlew build`

## 의존성

- **언어**: `Java 17`
- **프레임워크**: `Spring Boot`
- **빌드 도구**: `Gradle`
