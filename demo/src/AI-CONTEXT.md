# src

## 목적

프로젝트의 모든 소스 코드와 리소스 파일을 포함하는 최상위 디렉토리입니다.

## 주요 파일

(없음)

## 하위 디렉토리

- `main/` - 실제 애플리케이션을 구성하는 소스 코드(`java`)와 리소스(`resources`)가 위치합니다.
- `test/` - `main/`에 있는 코드들을 테스트하기 위한 테스트 코드가 위치합니다.

## AI 작업 지침

- 새로운 기능을 개발하거나 버그를 수정할 때, `main/` 디렉토리에서 작업을 시작합니다.
- 모든 코드 변경사항에 대한 테스트 코드를 `test/` 디렉토리에 작성하는 것을 원칙으로 합니다.
- `main`과 `test`는 동일한 패키지 구조를 유지해야 합니다.

## 테스트

- `./gradlew test` 명령을 사용하여 전체 테스트를 실행할 수 있습니다.

## 의존성

- 내부: 없음
- 외부: `Java`, `Gradle`
