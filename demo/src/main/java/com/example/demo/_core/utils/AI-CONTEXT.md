# utils

## 목적

도메인과 무관한 공통 유틸리티 클래스를 포함합니다.

## 주요 파일

| 파일명 | 설명 |
| --- | --- |
| `Resp.java` | REST API의 공통 응답 형식을 정의하는 래퍼 클래스입니다. `ok()`와 `fail()` 정적 메서드를 제공합니다. |

## 하위 디렉토리

(없음)

## AI 작업 지침

- 새로운 공통 유틸리티 클래스가 필요할 경우 이 디렉토리에 추가합니다.
- `Resp.java`는 모든 RESTful API 응답에 사용되어야 합니다. Controller에서 직접 `ResponseEntity`를 생성하지 마세요.

## 테스트

- 공통 유틸리티는 의존성이 없으므로 단위 테스트 작성이 용이합니다. `src/test` 아래에 동일한 구조로 테스트를 추가합니다.

## 의존성

- 외부: `Spring Framework`, `Lombok`
